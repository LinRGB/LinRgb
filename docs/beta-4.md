# LinRGB 1.0.0-beta.4 — square application icon

The launcher, application window and tray now use the same square LinRGB artwork. The native tray context menu from beta 3 is unchanged. This release does not change profiles, hardware permissions or RGB protocols.

Quit the old instance with **Ctrl+Q**, install the package for your distribution, then launch LinRGB again. `linrgb --version` should print `LinRGB 1.0.0-beta.4`.
